## Overview
Сейшельские Острова — архипелаг в Индийском океане из 115 островов, предлагающий программу Workcation Retreat Program (виза цифрового кочевника) на срок до 1 года и программу Permanent Residence by Investment для инвестирующих от USD 1,000,000+ в местный бизнес. Гражданство крайне ограничено — страна практически не натурализует иностранцев. Налоговая система территориальная: для неграждан отсутствует налог на доходы из иностранных источников. ^[https://www.seychelles.govtas.com]

## Per-Program Detail

### digital_nomad_visa — Workcation Retreat Program
- **Официальное название**: Программа Seychelles Workcation Retreat
- **Условия**: Удалённый работник, нанятый иностранной компанией, ИЛИ владелец бизнеса/фрилансер с иностранными клиентами. Подтверждение дохода/средств, достаточных для проживания. Действующая медицинская страховка/страховка путешественника с покрытием COVID-19. Отсутствие судимости. Подтверждение проживания. Сбор: €45 (около USD 50). ^[https://esim.holafly.com/visas/seychelles-digital-nomad-visa]
- **Срок**: 12 месяцев. Продление возможно при соблюдении условий.
- **Путь к гражданству**: Отсутствует — это гостевая программа, а не путь к ВНЖ.
- **Официальный источник**: https://www.seychelles.govtas.com
- **Оценка сообщества**: Работает хорошо — простая заявка, низкий сбор. Главное ограничение: короткий срок, не засчитывается в стаж для ВНЖ. Источник: форумы кочевников.

### investment_residency — Permanent Residence by Investment
- **Официальное название**: Программа ПМЖ Сейшельских Островов
- **Условия**: USD 1,000,000+ прямых инвестиций в новый или существующий бизнес. Не менее 5 лет делового участия/связи с Сейшелами. Отсутствие судимости. ^[https://www.imidaily.com/seychelles-investor-pr]
- **Срок**: Постоянный.
- **Путь к гражданству**: Крайне редкое. На Сейшелах нет стандартной процедуры натурализации для инвесторов. Гражданство — по происхождению, браку (с сейшельцем, 10+ лет) или по президентскому усмотрению.
- **Официальный источник**: https://www.imi.gov.sc (Immigration and Civil Status)
- **Оценка сообщества**: Неоднозначно — ПМЖ достижим для серьёзных инвесторов, но гражданство фактически закрыто. Источник: IMI Daily.

## Citizenship
- Гражданство только по происхождению (рождение от родителя-сейшельца).
- Брак с гражданином Сейшел: 10+ лет в браке, требуется одобрение президента.
- Стандартный путь натурализации через проживание для иностранцев отсутствует.
- Двойное гражданство: Сейшелы, как правило, не разрешают двойное гражданство.
- Паспорт: безвизовый доступ в ~150 стран, включая ЕС/Шенген, Великобританию, Сингапур, Россию.
- **Честная оценка**: Гражданство НЕ является реалистичной целью для большинства экспатов.

## Tax
- **Территориальная налоговая система**: доход из источников на Сейшелах облагается налогом; доход из иностранных источников для неграждан, как правило, не облагается налогом.
- Отсутствие подоходного налога с иностранного дохода для цифровых кочевников.
- 15% налог на бизнес для местных компаний.
- 15% НДС (налог на товары и услуги).
- Нет налога на прирост капитала, нет налога на наследство.
- Цифровые кочевники, работающие на иностранных работодателей: как правило, не облагаются сейшельским подоходным налогом с иностранной зарплаты.

## IT / Digital Nomad
Программа Workcation Retreat предоставляет право на пребывание сроком 1 год. Качество интернет-связи значительно улучшилось благодаря подводному кабелю Seychelles East Africa System (SEAS). На Маэ (Виктория, остров Иден) есть коворкинги. Стоимость жизни высокая — Сейшелы импортируют большинство товаров. Лучше всего подходит для краткосрочных (3–12 месяцев) периодов удаленной работы, а не для долгосрочного планирования ВНЖ.

## Yacht / Maritime
Сейшелы — крупный центр яхтинга в Индийском океане. Порт Виктория (Маэ) обслуживает суперъяхты. Администрация морской безопасности Сейшел (SMSA) управляет регистрацией судов. Популярный район круизного плавания в Индийском океане (Мальдивы, Маврикий, Мадагаскар). Международные капитанские удостоверения признаются.

## Notes for RU citizens
Безвизовый въезд на 90 дней для граждан РФ. Прямые рейсы из Москвы возобновлены в 2024/2025. Проблем с санкциями нет. Российский туризм значительно вырос. Банковское обслуживание: более ограничено, чем на Маврикии. На Сейшелах есть заметное русскоязычное сообщество экспатов.

## Country Card

Сейшельские Острова — потрясающий архипелаг в Индийском океане из 115 островов с самым высоким ВВП на душу населения по ППС в Африке (~$35,000) и одним из сильнейших паспортов континента (~150 безвизовых направлений). Виктория (Маэ) — одна из самых маленьких столиц мира. Программа Workcation Retreat предлагает пребывание на 1 год для удалённых работников с минимальными затратами (€45). ПМЖ доступно при инвестициях от USD 1,000,000. Налоговая система территориальная — доходы из иностранных источников для неграждан, как правило, не облагаются налогом. Гражданство для иностранцев фактически закрыто.

### Well-known strong points
- Самый высокий ВВП на душу населения в Африке (~$35,000 ППС); сильный паспорт (~150 безвизовых направлений)
- Территориальная налоговая система — отсутствие подоходного налога на иностранный доход для неграждан
- Программа Workcation Retreat Program: пребывание для удаленной работы на 1 год, сбор всего €45
- Верховенство закона 0.63 (43-е место из 142), Freedom House 79/100 — устойчивое демократическое управление
- Английский и французский являются официальными; трехъязычное население
- Направление для яхтинга мирового класса с растущей инфраструктурой для суперъяхт

### Well-known problems
- Гражданство фактически закрыто — стандартного пути натурализации для иностранцев нет
- Очень высокая стоимость жизни — большинство товаров импортируется; жизнь экспатов дорогая
- Крошечное население (~130,000) и экономика — крайне ограниченный внутренний рынок
- Программа Workcation Retreat Program не ведет к ПМЖ или гражданству; долгосрочный путь для цифровых кочевников отсутствует
- ПМЖ требует инвестиций от USD 1,000,000+ — высокий порог входа
- Инфраструктура ограничена за пределами Маэ; интернет улучшается, но может быть нестабильным
