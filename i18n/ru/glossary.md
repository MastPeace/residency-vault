## How to read this site

Каждая страница страны содержит шапку с ключевыми фактами, панель мониторинга, условия каждой программы и таблицу «Обзор страны» с данными из источников. Этот глоссарий объясняет колонки, обозначения и сокращения, которые вы там встретите.

## Country list columns

Нажмите на заголовок колонки для сортировки; нажмите на * рядом с заголовком для краткого пояснения. Наведите курсор на значение, чтобы увидеть его источник.

| Column | Meaning |
|---|---|
| Регион | Код региона; наведите курсор для полного названия (см. **Коды регионов**). |
| Теги | Редакционные #теги (см. **Теги соответствия**). |
| Программы | Иконки маршрутов получения ВНЖ, которые предлагает страна (см. **Типы программ**). Закрытые или недоступные маршруты не отображаются. Кнопки программ над таблицей фильтруют страны, предлагающие все выбранные маршруты. |
| Годы до гражданства | Лет легального проживания до подачи заявления на гражданство по стандартному пути. `10+ yr` означает десять лет или более; `no path` означает отсутствие реального пути для иностранца. |
| Безвизовый въезд | Сила паспорта: количество направлений, которые владелец паспорта этой страны может посетить без визы (безвизовый подсчет по типу Henley). Описывает паспорт, который вы получите после натурализации, а не тот, который у вас есть сейчас. |
| Индекс стоимости | Индекс стоимости жизни Numbeo, где Нью-Йорк = 100; чем ниже, тем дешевле. Диапазоны на странице показаны как их средняя точка. |
| Аренда $/мес | Типичная месячная арендная плата за 1-комнатную квартиру, обычно в центре города, пересчитанная в доллары США по приблизительным фиксированным обменным курсам (диапазон остается диапазоном). Это приблизительная цифра для сравнения, а не оферта. |
| Мин. инвестиции | Минимальная квалифицирующая сумма по инвестиционному маршруту ВНЖ страны (в стиле Golden Visa: недвижимость, фонд, бизнес или депозит) в долларах США. Суммы в других валютах пересчитаны по приблизительным фиксированным курсам и помечены `≈` (округлены до двух значащих цифр); наведите курсор, чтобы увидеть исходную сумму и цитату из источника. Пустое поле означает, что маршрут закрыт, отсутствует или не имеет указанной суммы. |
| Виза кочевника | Указывает, существует ли ВНЖ для цифровых кочевников или удаленной работы, с основным требованием к доходу в месяц или год в долларах США (пересчитано и помечено `≈`, если на странице используется другая валюта). `No` означает, что на странице указано его отсутствие; пустое поле означает, что на странице об этом не сказано. |
| Налог % | Диапазон эффективной ставки подоходного налога для удаленного работника в процентах. Только для ориентира: реальный налог зависит от дней налогового резидентства, режима и дохода. |
| Доверие | Уровень достоверности страницы: насколько хорошо она подкреплена источниками (см. **Достоверность** ниже). 3 деления = высокий, 2 = средний, 1 = низкий. |

Мин. инвестиции, Виза кочевника и Налог % извлекаются со страниц стран в `data/facts.json`; каждое значение сохраняет цитату, из которой оно взято, и удаляется, если цитата не найдена на странице.

## Confidence

- **Высокая**: ключевые факты подтверждены официальными или авторитетными источниками.
- **Средняя**: сочетание официальных источников и вторичных или оценочных данных.
- **Низкая**: в основном непроверенные данные, или важная информация отсутствует. Проверьте источники, прежде чем полагаться на них.

## Fit tags

Теги носят редакционный характер и помогают фильтровать список. Они не являются официальной классификацией.

- **#pass** (Сильный паспорт): гражданство даст высокий показатель безвизовых стран.
- **#it** (IT-дружелюбный): маршрут для удаленной работы или технологических специалистов, а также подходящая среда для IT-специалистов.
- **#path** (Четкий путь): хорошо прописанный, задокументированный путь от ВНЖ к паспорту.
- **#ru** (Популярно у россиян): распространенное направление среди русскоязычных заявителей.
- **#yacht** (Капитан яхты): страна с морской или яхтенной инфраструктурой, актуальной для капитанов.

## Source marks

- **✓**: значение получено из официального или авторитетного источника.
- **~**: оценка или вторичный источник; значение может быть устаревшим.
- **Нет надёжных данных / Нет свежих данных**: ничего достоверного не найдено. Поле намеренно оставлено пустым, а не заполнено догадкой.

## Program types

Для каждого типа существует страница сравнения по странам.

- 💰 [Инвестиционный ВНЖ](concepts/investment-residency.html): ВНЖ в обмен на инвестиции, часто называемый Золотой визой.
- 🛂 [Гражданство за инвестиции](concepts/citizenship-by-investment.html): паспорт в обмен на взнос или инвестиции (CBI).
- 🏦 [ВНЖ на основании пассивного дохода](concepts/passive-income-residency.html): резидентство на основе стабильного дохода, не требующего местной работы.
- 🌴 [ВНЖ для пенсионеров](concepts/retired-residency.html): резидентство для пенсионеров с зарубежной пенсией.
- 💻 [Виза цифрового кочевника](concepts/digital-nomad-visa.html): резидентство для людей, работающих удалённо на иностранных клиентов или работодателей.
- 💼 [ВНЖ через трудоустройство](concepts/employment-residency.html): резидентство, привязанное к местному предложению работы.
- 🧠 [Высококвалифицированные специалисты](concepts/highly-skilled-employment.html): ускоренные разрешения для квалифицированных специалистов, включая Голубую карту ЕС (EU Blue Card).
- 🚀 [Стартап / предприниматель](concepts/startup-entrepreneur.html): резидентство для основателей и владельцев бизнеса.
- 🎓 [Студенческий ВНЖ](concepts/student-residency.html): резидентство для зачисленных студентов.
- 👨‍👩‍👧 [Воссоединение семьи](concepts/family-reunification.html): резидентство для родственников законного резидента или гражданина.
